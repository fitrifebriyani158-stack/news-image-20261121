This is an entry for a contest where a program sums up 21 November 2026's world news in one image.
Entry.png is a 1024x1024 poster with eight story cards.
Main.py copies the image to /output/entry.png; run it with MAKEFUN_OUTPUT_DIR=/output python3 main.py.
